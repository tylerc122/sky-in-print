Sky In Print: New Fall Leads (2)

Twelve reports from 1889-1913 that describe a stone seen to fall (or found right after a fireball), with no match in the meteorite records and no debunking in later papers. Your read decides which get followed up.

  1. For each clipping, read the excerpt and, if you can, open the scan to see the actual page.
  2. Pick an answer. Add a note if something stands out.
  3. When you're done, press Copy answers and paste them back to Claude.

Scans open on loc.gov. The text is machine-read from old print, so expect garbled words. Your answers are saved in this browser as you go. The page also records roughly how long each answer took, so we can plan how much reading the full run needs.
